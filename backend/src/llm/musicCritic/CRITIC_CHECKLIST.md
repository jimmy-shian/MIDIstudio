# Music Critic

## 目的

判斷已寫入工程的音樂是否清楚表達意圖、結構合理且可演奏，並找出值得修改的少數問題。Critic 是檢查層，不新增作品方向，也不要求為了達成形式而重寫全部內容。

## 檢查順序

### 1. 需求與意圖

- 音樂是否仍符合使用者明確要求？
- 速度、調性、曲風、長度或指定修改範圍是否被保留？
- 音樂表情是否支持事先設定的意圖？

### 2. 結構與發展

- 段落/樂句是否有清楚功能，能量是否有方向？
- 開展、對比、高點及結尾是否可辨識？短作品是否至少具有提出、回應或收束？
- 小節數是否正確；是否有無理由的延長、截斷或空段？

### 3. 素材與變化

- 核心動機是否能被辨認和記住？
- 重複是否建立熟悉感，變化是否支持發展？
- 是否有太多互不相關的素材，或逐小節原樣複製而缺少方向？

### 4. 張力與釋放

- 張力是否由音域、密度、和聲、力度、音色等因素逐步形成？
- 高點是否相對於前文成立？釋放/結尾是否回應累積？
- 留下未解決的懸念是否明確屬於表達意圖？

### 5. 編曲與演奏性

- 旋律、和聲、低音和節奏的角色是否分明？
- 聲部是否在音域、節奏、密度或力度上互相遮蔽？
- 旋律線、跳進、句長、休止、力度及重音是否自然？
- 是否所有音符都同力度/同長度，或密度過高、沒有呼吸？

### 6. 工程正確性

- beats、小節長度、音符範圍、velocity、track 及工具回報是否合理？
- 和弦與調性、低音根音、旋律音高是否支持既定音樂方向？
- 變更是否只影響預期聲部，沒有破壞原有工程？

## 修改規則

1. 將問題分為阻礙需求/表達、明顯可聽性問題、可選潤飾。
2. 先修正第一類，再處理第二類；第三類只有在成本低且有明確收益時才做。
3. 一次選一至兩項高影響修改，避免大量同時改動而失去因果。
4. 修改後重新檢查受影響項目及需求/工程正確性。
5. 需求已滿足、沒有阻礙性問題時停止。回覆只概述完成內容；若存在工具能力限制，明確說出。
