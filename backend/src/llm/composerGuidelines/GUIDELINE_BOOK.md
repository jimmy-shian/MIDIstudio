# MIDIstudio Guideline Book

本文件是作曲決策的主要規格。`index.ts` 是提供給模型的精簡執行摘要；修改寫作原則時，先改本書，再同步摘要。樂理數值與 MIDI 工程事實由 `../musicKnowledge.ts` 提供，不在此重複維護。

## 任務目標

作品不是規則的拼貼。所有音樂決策都應共同服務使用者的表達意圖。使用者已明確指定的調性、長度、曲風、配器或修改範圍優先；未指定的細節採用一致、節制、容易聽懂的選擇。不要把一次簡短需求擴寫成不必要的大型作品。

## 創作流程

### 1. 決定作品想表達什麼

把需求整理成一句創作意圖，描述情緒、場景或敘事動作，例如「平靜地前進，逐步變得堅定」。辨認情緒能量、明暗、動態方向和預期聆聽情境。由意圖推導速度、調性/調式、音色、節奏性格和音域；不要只因某調性被刻板印象貼上情緒標籤。

輸出給自己的決策應簡短：意圖、必要限制、將採用的音樂方向。若使用者只要求一個局部修改，沿用工程既有方向，不另起完整創作計畫。

### 2. 設計整體發展

先確定需求的小節數與段落功能，再分配能量。短作品也需要方向，例如「提出—回答—收束」；較長作品可安排引入、建立、對比、高潮和結尾。每一段至少要有可辨識的功能差異，差異可來自密度、音域、節奏、和聲、音色或力度，不必全部同時改變。

若沒有指定形式，選擇能以目前長度表達清楚的簡單形式。段落長度與總長必須一致；不要為了套用形式擅自增加小節。

### 3. 建立少量核心素材

先選一至三個核心素材：旋律動機、節奏型、低音型或和聲色彩。每個素材應短、可辨認、可再次使用，並能從作品意圖推導出來。先建立一個有辨識度的材料，再補足支援它的材料，避免一次填滿所有聲部。

動機可以用輪廓、節奏、節拍位置、音程或休止辨認。若工具與需求只容許直接寫入音符，先在內部規劃動機的節奏與輪廓，再轉成音高及 beats。

### 4. 重複與變化

重現核心素材，使聽者能建立記憶；每次變化只改一至兩個主要面向，例如移調、改變尾音、改變節奏、擴張音域、改變配器或增加密度。變化要能說明其段落功能。不要每小節都換一個新動機，也不要把逐音複製誤當成發展。

可用的發展方式：原樣重現、序進、節奏增值/減值、音程擴張/收縮、呼應、切分、留白、音域轉移、分層加入/撤去。保留足以辨識來源的特徵。

### 5. 建立張力與釋放

選擇少數可控制的張力軸：旋律上行或音域擴張、節奏密度增加、和聲遠離穩定中心、力度增強、音色變亮、低音持續/推進、休止前的期待。張力應逐步形成並指向清楚的高點或落點；之後用音域回落、節奏放鬆、和聲解決、力度收斂或留白釋放。

避免所有軸線同時達到最大值。高潮應相對於前文成立，釋放應與累積相稱。若作品追求懸而未決，保留不解決可以是有意選擇，但要讓聽者感到它是結尾意圖而非遺漏。

### 6. 編曲

為每個聲部指定角色：旋律負責焦點，和聲提供色彩與支撐，低音建立重心和推進，節奏聲部建立脈動與重音。若加入 pad、對位或裝飾聲部，也要說得出它的功能。先確保主次，再決定音符數量。

留出頻段、節拍位置和音域空間。伴奏避免長時間與旋律同節奏、同音域、同力度；低音避免和旋律爭奪焦點。聲部可用不同節奏、音域、音色、密度和力度區隔。留白是編曲的一部分。

### 7. 演奏化

檢查音域、句長、呼吸/換弓或手部跨度（依樂器而定）、重音位置、力度層次、音符長短、休止和句尾。旋律要有方向與可唱性；節奏要能自然演奏。避免無理由的極端跳進、過度密集、每音同力度或整齊到失去樂句感。

MIDI 工程限制、音符範圍、時間單位與工具參數以 `musicKnowledge.ts` 和工具 schema 為準。本節的演奏化是音樂判斷，不得覆蓋工程硬限制。

### 8. 檢查與修改

完成一個可聽的整體後，依 `../musicCritic/CRITIC_CHECKLIST.md` 檢查。先修正會破壞表達或可聽性的問題，再處理局部潤飾；一次修改最重要的一至兩項，重新檢查後再決定是否值得繼續。沒有重大問題且需求已滿足時停止。

## 決策優先序

1. 使用者明確需求與既有工程連續性。
2. 作品表達意圖及整體發展。
3. 核心素材的辨識度與發展。
4. 聲部平衡、演奏性和局部細節。
5. 可選的裝飾和技術複雜度。

若兩項選擇衝突，採用優先序較高者，並避免無必要地擴大修改範圍。
